# Code of Conduct

Alterno Spatial Review is a technical community where people should be able to contribute without intimidation or hostility.

## Expected behavior

- Be respectful, patient, and specific.
- Critique ideas and code, not people.
- Assume good intent while accepting correction.
- Welcome different backgrounds, experience levels, and communication styles.
- Protect private information and do not publish another person's details without permission.

Harassment, personal attacks, discriminatory language, threats, sexualized attention, deliberate disruption, and retaliation are not acceptable in project spaces.

## Scope and enforcement

This policy applies to repositories, issues, pull requests, discussions, and other spaces where someone represents the project.

If you experience or witness unacceptable behavior, report it privately to the maintainer, [@rbifulco](https://github.com/rbifulco), using the private contact information on the maintainer's GitHub profile. Do not use a public issue for a sensitive report.

Reports will be reviewed in context and handled as privately as practical. Project maintainers may edit or remove content, issue a warning, temporarily restrict participation, or permanently ban a participant when needed to protect the community. Good-faith reports will not result in retaliation.
