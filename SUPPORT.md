# Support

- Use [GitHub Discussions](https://github.com/rbifulco/alterno-spatial-review/discussions) for integration questions, design exploration, and help deciding whether something is a bug.
- Use [GitHub Issues](https://github.com/rbifulco/alterno-spatial-review/issues) for reproducible bugs and actionable proposals.
- Use the private process in [SECURITY.md](SECURITY.md) for suspected vulnerabilities.

Include the package version, environment, relevant manifest or scene shape, and a minimal reproduction whenever possible. Support is community-based and provided on a best-effort basis.
